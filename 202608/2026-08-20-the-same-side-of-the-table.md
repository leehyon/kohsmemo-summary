# The Same Side of the Table

- Tags: #career

## TL;DR
管理者与下属开会时必须始终站在同一战线，团队失误就是自己的失误；用接管、暂停、防守等方式保护下属，能建立信任并避免恐惧文化。

## Summary
这篇文章提出管理者与直接下属开会时的核心原则：始终坐在桌子的同一边，即全力支持下属。作者认为，团队的表现就是管理者的延伸，因此不应在会议上指责或撇清关系。

**逻辑脉络**
- 从谈判桌的比喻引入：同一边代表同一团队，即使有分歧也要一致对外。
- 列举错误行为：不能附和批评、不能袖手旁观、不能加入质问，也不能说“我不同意”。
- 给出补救方法：接管会议、暂停并稍后继续、或表示“我们对此还没准备好”并代为防守。
- 举例：为中级团队成员向董事会成员汇报做准备，包括预演、分工、承诺做“保护者”。
- 解释重要性：体育队不公开指责队友，因为指责无法开脱自己，且会制造恐惧文化，损害长期表现。

**底层逻辑**
- 第一性原理：团队是管理者的延伸，团队失误即管理者失误。
- 支持下属不是过度保护，而是给予自主权与后果的同时，不让他们成为众矢之的。
- 荣誉感是长期吸引优秀人才的关键，优秀的人只愿与有荣誉感的人共事。

**Takeaways**
- 始终与直接下属站在同一边，即使他们犯错也不公开指责或撇清。
- 下属发言困难时，可主动接管、暂停话题，或代为防守，避免“公开处刑”。
- 仅在下属违背明确指示且表现极差时可保持中立，但要做好随后解雇的准备。
- 通过充分准备和明确承诺，增强团队在高风险会议中的信心。
- 维护团队荣誉能避免恐惧文化，吸引并留住优秀人才。
