## TL;DR
作者亲测 Hermes Agent 半年，认为其最大优势是能直接操作电脑，通过 Telegram 查告警、回飞书、写代码等。核心在于技能与记忆系统，让 AI 助手与工作流深度粘合。

## Summary
作者分享了使用 Hermes Agent 近半年的经验，认为其核心价值在于能直接操作电脑，实现从对话到行动的闭环。文章详细介绍了 Hermes 的安装、配置、日常用途、Skills 技能机制、记忆系统以及踩过的坑。

**逻辑脉络**
- 从 Hermes 的定义出发：本地 AI 助手 CLI，通过 Telegram 交互，能调模型并操作电脑。
- 对比 ChatGPT：强调“能直接动手”是关键差异。
- 按用途逐一说明：查告警、回飞书、盯行情、写代码、写博客、管定时任务。
- 介绍进阶能力：Skills 系统沉淀操作流程，记忆系统积累上下文，并最终总结出“粘合度”这一核心观点。

**底层逻辑**
- 核心假设：AI 助手的价值取决于它与用户环境的集成深度，而非模型参数大小。
- 方法论：通过工具集（内置 + MCP）扩展操作能力，通过 Skills 固化经验，通过记忆系统管理上下文。
- 观点：脚本化比纯 agent 更稳定，按场景选择模型（快 vs 强）。

**Takeaways**
- 用 Telegram 作为入口，实现移动端随时指挥电脑。
- 善用定时任务自动推送信息（如晨报），减少主动查询。
- 用 Skills 记录复杂操作，如告警检查，提升复用效率。
- 记忆系统（内置 + OpenViking）让上下文不断层，工作回顾自动沉淀。
- 复杂推理任务需切换更强模型，日常快速任务用闪速模型。
