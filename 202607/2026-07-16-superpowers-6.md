## TL;DR
Superpowers 6 速度提升 50%，成本降低 60%，通过合并审查代理和自动化优化实现，现已发布。

## Summary
Superpowers 6 是一次重大更新，在保持高质量的同时，将构建时间缩短 50%，token 消耗减少 60%。这些改进源于使用 Anthropic 的 Fable 模型进行自动化优化实验，最终合并了代码审查与规范审查代理，并优化了任务分配逻辑。

**逻辑脉络**
- 团队原计划发布 Superpowers 5.2，增加了多项新功能与修复。
- 在短暂获得 Fable 访问权限后，作者利用其进行自动化实验，目标是降低 token 成本。
- 首次优化：将审查指令改为 shell 脚本预生成 diff 包，减少了 git 命令调用，节约约 10%。
- 第二次优化：合并审查代理（代码审查 + 规范审查），节省额外 15%。
- 后续通过 autoresearch 循环运行 25 个实验，找到了最佳配置：使用 Opus 作为协调器、有条件地使用 Haiku 作为实施者、精简审查协议等。
- 最终在 Anthropic 和 Codex 评估套件上验证了改进效果。

**底层逻辑**
- 传统上，Superpowers 的慢和贵源于大量前期规划、严格 TDD 和双重审查，这些确保了输出质量但效率低下。
- 优化思路是减少不必要的代理调用、简化审查流程，并为不同难度任务分配合适的模型（如简单任务用 Haiku）。
- 关键假设：合并审查代理不会降低质量，通过预生成审查包可避免重复 git 操作。

**Takeaways**
- Superpowers 6 相比 5.x 版本，构建时间降低 50%，token 消耗减少 60%。
- 主要改进点：合并代码审查与规范审查代理；预生成 diff 审查包；根据任务复杂度动态选择实施模型。
- Fable 的 autoresearch 循环在 36 小时内完成了 25 个实验，成本仅 $165，是快速迭代的关键。
- 强大的评估套件（superpowers-evals）确保了跨平台（Anthropic、Codex）的改进可量化。
- 新版本已开源，可直接从 GitHub 安装。
