# Using the internet like its 1999
- URL: https://joshblais.com/blog/using-the-internet-like-its-1999/
- Added: 2026-07-15 01:46:13

## TL;DR
本文倡导回归 1999 年的互联网使用方式，通过 RSS、IRC、邮件等协议逃离算法和 AI 垃圾，找回自主性与真实性。

## Summary
本文指出现代互联网被算法和 AI 生成内容（slop）侵蚀，用户被困在信息茧房中。作者主张回归 1999 年的互联网使用方式，即直接使用底层协议（如 HTTP、IRC、SMTP），以夺回对注意力和内容的控制权。

**逻辑脉络**
- 问题：社交媒体和视频平台依赖算法推送，导致内容同质化和 AI 垃圾泛滥，用户失去自主性。
- 历史参照：1999 年互联网只有 4% 人口在线，协议设计质朴，用户是主动的“网民”而非被动消费者。
- 解决方案：通过 RSS 聚合内容、使用 IRC/XMPP 进行文本交流、自建搜索引擎和存档工具、采用 POSSE 方法（自有平台同步到社交网络）、禁用 JavaScript 和广告拦截。
- 结论：拥抱真实人类，追求不完美的真实性，拒绝算法制造的虚假世界。

**底层逻辑**
- 核心假设：协议的开放性优于平台封闭性；人的自主选择优于算法推荐；真实性优于人造内容。
- 第一性原理：互联网本质是数据传输的管道，用户应直接操作数据，而非受制于前端美化。

**Takeaways**
- 使用 RSS 阅读器（如 Miniflux）聚合自己选择的创作者，拒绝算法推送。
- 用 IRC 或 XMPP 进行文本聊天，加密通信（如 OMEMO），提高信噪比。
- 自建搜索引擎（如 Searx），用高级查询语法获取精确结果。
- 本地存档重要内容（如 Emacs 脚本 + Syncthing），对抗链接失效。
- 将社交媒体仅作发布渠道，以邮件为通讯核心，辅以 PGP 加密。
