# Attention is all you have
- URL: https://www.alicegg.tech//2026/09/21/attention.html
- Added: 2026-09-23 01:25:00
- Tags: #life #view

## TL;DR
文章用俄罗斯方块效应说明：注意力会被长期关注塑造。推荐算法劫持注意力，把大脑钥匙交给平台；我们应回到博客、RSS 等主动、较慢的有意图互联网。

## Summary
文章借“俄罗斯方块效应”说明：长期关注什么，大脑就会被什么塑造。作者担忧，推荐算法正替我们决定看什么，把注意力变成可劫持的资源，等于把大脑钥匙交给平台。

**逻辑脉络**
- 从俄罗斯方块效应切入：反复注意会改变感知与思维。
- 再列举 YouTube、Spotify、LinkedIn、Reddit 等被算法与商业动机劫持注意力的场景。
- 对比早期互联网：用户靠书签、博客、RSS 主动选择内容，而非由单一应用投喂。
- 结论：有意图的互联网仍存在，但需要用户主动、耐心地重建习惯。

**底层逻辑**
- 注意力是有限且可塑的认知资源。
- 默认由平台推荐，就是把选择权外包给以停留和广告为目标的系统。
- 主动互联网要求意图、筛选与较慢的信息节奏。

**Takeaways**
- 你长期关注的内容会反过来塑造你。
- 推荐算法为留存与广告优化，不必然为你的利益优化。
- 把屏幕交给平台，等于把注意力控制权交出去。
- 回到博客、RSS、教程等主动信息源，习惯需要坚持。
- 关键不是逃离互联网，而是重新成为注意力的主人。
