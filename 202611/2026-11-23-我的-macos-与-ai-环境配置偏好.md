## TL;DR
作者重装 macOS 后整理的精简开发与 AI 环境配置：Ghostty + Zsh、fnm 与 pnpm、Codex 和 Herdr 等 Agent 工具，外加实用小软件，主打少而核心、规避包管理心智负担。

## Summary
这篇文章是作者重装 macOS 后整理的一套开发与 AI 环境配置清单，覆盖终端、Shell、Node 工具链、Coding Agent 与常用软件。核心主张是「以尽量少而核心的配置变动，撑起体验较为舒适的开发流程」，并尽量回避包管理带来的心智负担。

**底层逻辑**
- 配置简单优先于功能强大：从 iTerm2 转向 Ghostty，只保留少量关键项。
- 统一字体与主题（Sarasa Mono SC + Catppuccin），减少跨工具的视觉与配置差异。
- 避免包管理器污染：npm 全局包会随版本切换隔离且有权限问题，故全局包走 pnpm 独立脚本，Coding Agent 尽量用原生安装命令。

**Takeaways**
- 终端：Homebrew 起步，Ghostty + Nerd Font / Sarasa，Zsh + Powerlevel10k，fnm 管理 Node，pnpm 装全局包，fastfetch / btop 展示信息。
- AI 工具：Codex 用官方脚本安装并关闭共享 daemon，以便 Herdr 准确恢复会话；Herdr + Sheprd 提供多 agent 面板。
- 其他 Agent 可经 OpenRouter、CLIProxyAPI、Magpie 等中转接入 Pi 或 Claude Code，但应使用 API 额度而非转售订阅。
- 用量统计从 WakaTime 转向 Tokscale Tracker 与 Vibe Usage，并自写 TUI 看板。
- 实用软件：BetterCmdTab、LinearMouse、Crisp、IINA、MacPacker、Maccy、Stats、豆包输入法。
