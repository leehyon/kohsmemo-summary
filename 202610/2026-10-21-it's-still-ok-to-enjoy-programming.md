# It's still OK to enjoy programming
- URL: https://chriskiehl.com/article/it-is-still-ok-to-enjoy-programming
- Added: 2026-10-21 01:18:08

## TL;DR
工作里的编程经济学已变，但工作不等于生活；周末为乐趣写代码、探索难题，甚至用 AI 辅助编程，都无需经济理由，享受编程仍然可以。

## Summary
作者回应 Hacker News 上关于 AI 编程的悲观论调：工作场景中手写代码的经济性确实变了，但工作不等于生活，享受编程仍然成立。文章以个人周末项目为例，说明为乐趣写代码、探索冷门主题和钻研难题本身就有价值。

**底层逻辑**
- 工作与生活分离：商业产出逻辑不应吞掉个人乐趣。
- 编程的回报可以来自探索、成长与理解难题，而非效率或经济回报。

**Takeaways**
- 工作代码受商业价值约束，个人项目不必如此。
- 手写 Breakout 克隆、研究 Java 类型安全等，乐趣本身就是目的。
- 悲观信息流会传染，误以为“不该再享受”；断开后即消退。
- 享受事物无需经济辩护，AI 辅助的 vibe coding 也可以是另一种乐趣。
