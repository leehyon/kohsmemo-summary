# Nobody should type code by hand anymore
- URL: https://ghuntley.com/agency/
- Added: 2026-10-16 02:38:24

## TL;DR
手写代码时代结束：模型已够强，瓶颈在操作者。自建智能体、用循环与验证工程化 AI，锁定模型、读模型卡、抛弃无效技能包，靠速度、好奇心与能动性取胜。

## Summary
文章整理 Geoffrey Huntley 与 Josh Wulf 的对谈，核心判断：手写代码的软件工程师已没有位置，AI 智能体、循环与验证正在重写软件工程。作者认为模型早已够好，瓶颈在操作者心态与工程能力。

**逻辑脉络**
- 从 Cursor 与循环实验，到 filesystem-as-state、Z80 重建，说明软件可规格化重建，护城河转向基础设施或锁定。
- AI 使用成为就业必需；企业禁止 AI 时员工应离开。
- 补贴窗口像免费大学，但会关闭；单位经济学使 AI 不可避免。
- 旧 PR 审查失效；用属性测试、Nix、确定性平台与预提交钩子验证。
- 智能体放大代码库好坏；技能包多属占星，模型卡与自建 agent 更重要。
- 迭代速度、白板防御、好奇心与能动性是关键。

**底层逻辑**
- 模型是操作者能力的镜子；瓶颈是理论心智与验证，不是模型。
- 实现可外包给硅或承包商；人类保留愿景与验证。
- 确定性优于概率：能自动化就自动化，用工程约束替代祈祷式提示。
- 软件不再为阅读而写，而为可解释、可验证、可演进而写。

**Takeaways**
- 停止手写代码，学会驱动循环与智能体。
- 自建 coding agent，理解其约 300 行核心机制。
- 删除或定期重估 skills、AGENTS.md、MCP，先读模型卡。
- 锁定一个模型，减少切换，专注愿景与验证。
- 用属性测试、Nix、预提交钩子和确定性平台建立 back pressure。
- 快速做到第十版，用使用反馈收敛；保持好奇心与 agency。
