# 你不知道的具身智能：从小机器狗到 Optimus
- URL: https://tw93.fun/2026-06-07/robot.html
- Added: 2026-06-08 02:20:02
- Tags: #agent #robotics

## TL;DR
文章介绍低成本小机器狗（约 200 元）的软硬件集成经验，分析机器人空间感知瓶颈与 VLA 动作表示演进，对比 Tesla、Figure 等公司路线，并给出软件工程师入行建议。核心难点在能耗、数据及 Sim2Real 差距。

## Summary
- 作者组装了一台低成本小机器狗（约 200 元），采用异构架构（STM32 + ESP32-C3 + ASRPRO），实现语音唤醒、云端 LLM 对话、舵机动作控制等能力。关键经验是：软硬件结合的坑多在周边硬件（供电、舵机偏差、联网超时），MCP 概念落地为设备能力清单。
- 机器人的空间感知是核心瓶颈：小机器狗缺乏位姿、地图和遮挡处理，无法执行“往左走两步绕过椅子”。常用 3D 表示有 Occupancy、点云、NeRF/3D Gaussian Splatting、3D Scene Graph，各有利弊。VLA 正从 2D 向 3D 迁移，如 3D-VLA、SpatialVLA 尝试将 3D 场景与动作生成统一。
- VLA 动作表示演进：离散 token（RT-1/2）→ 动作块（ACT）→ 扩散生成（Diffusion Policy）→ 流匹配（π0/π0.5/SmolVLA）→ 高低频双系统（Helix/Gemini Robotics）。接口减少但排错难度增加，工程上需考虑精度、延迟和跨机器人迁移。
- 机器人系统分为大脑（100ms - 1s）、小脑（1ms - 50ms）、肢体（μs - 10ms）三层，每层时间尺度不同。能耗（执行器与电池）和训练数据（遥操作、真机、仿真、人类视频、合成数据）是两大硬约束，仿真到真机（Sim2Real）仍有差距。
- Tesla Optimus 被视为工程样本：纯视觉、FSD 迁移、自研执行器、工厂试跑。手部设计（无销钉关节、各向异性刚度）和 AI 训练（多任务 multi-head、4 类数据源）是重点。量产难点在于执行器良率、供应链、手部可靠性及真实工位 ROI。
- 主要公司路线对比：Tesla（自研整机 + 制造规模）、Figure（全身 VLA）、Google DeepMind（通用模型层）、NVIDIA（工具链）、Boston Dynamics（传统控制）、宇树（高性价比硬件）、智元（全栈平台）。工厂场景为第一站，家庭场景最难。
- 软件工程师进入具身智能需补充：嵌入式/实时系统、机器人运动学、控制基础、感知/SLAM、模仿/强化学习、数据工程。建议从低成本硬件项目入手，逐步理解端云协同、MCP、动作表示，再研究 ACT、Diffusion Policy、VLA 等算法文献。核心概念可归结为“感知、空间、动作、力矩”，难度依次递增。
