# The control layer is the product, not the model
- URL: https://belderbos.dev/blog/control-layer-is-the-product/
- Added: 2026-06-30 01:58:45
- Tags: #agent

## TL;DR
AI 产品的核心是控制层（路由、验证、状态等），而非模型。通过状态机、类型边界、评估器和结构化生成，将不可预测的模型嵌入可预测的工作流。

## Summary
文章指出，AI 产品的核心不是模型本身，而是包裹模型的“控制层”（control layer）。模型如同缸中之脑，而路由、验证、状态、审计等工程代码构成了真正的产品。作者通过四个模式说明如何构建可靠的控制层：确定性状态机、类型化边界、评估器与护栏、结构化生成。

**逻辑脉络**
- 引用 Gary Bernhardt 的观点：控制层比模型有更多低垂果实，“Agent”一词低估了该层的价值。
- 解释“Agent”和“Harness”的局限性：简单的 while True 循环无法应对真实工作流。
- 提出四个实践模式，每个模式解决一个控制层的关键问题。
- 总结：前沿模型吸引目光，但控制层交付产品。

**Takeaways**
- 控制层决定了产品的确定性：通过状态机将模型限制在安全的下一步。
- 模型应作为可替换的函数调用，通过 Python Protocol 隔离依赖，使路由、回退、测试变得简单。
- 采用生成-评估分离：模型输出必须经过验证和业务规则检查，失败时反馈循环而非崩溃。
- 结构化输出（如 Pydantic）将字符串转换为类型化数据，让下游代码变为普通 Python 逻辑。
- 构建控制层时，优先考虑状态、幂等性、审计和回滚四个问题。
