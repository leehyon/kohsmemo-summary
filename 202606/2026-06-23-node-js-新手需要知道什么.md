# Node-js 新手需要知道什么

- Added: 2026-06-23 08:26:18

## TL;DR
Node.js 新手入门需掌握官方教程、常用框架（Next.js/NestJS）、ORM、Zod 和 PM2，并善用 GitHub 现有方案，避免重复造轮子。

## Summary
文章介绍了 Node.js 新手入门所需的核心知识和资源。作者强调 JavaScript 生态的丰富性，并分享了利用 AI 时节省 token 的技巧——让 AI 搜索 GitHub 现有方案。入门教程推荐官方学习入口（nodejs.org/learn）、MDN 的 Express Node.js 教程，以及《Node.js Best Practices》实践指南。框架选择上，小项目用 Hono，中项目用 Next.js（React 生态）或 Nuxt.js（Vue 生态），大项目用 NestJS（适合找工作）。数据库方面推荐 ORM（如 Prisma），并强调使用 Zod 验证前端数据以确保安全。最后提到 PM2 用于进程管理。

**逻辑脉络**
- 作者首先表达对 JavaScript 生态的信任，并介绍 Node.js 的作用。
- 分享省 token 技巧：让 AI 搜索 GitHub 已有方案。
- 逐一列出新手入门资源：官方教程、MDN 教程、Best Practices。
- 根据项目规模推荐不同框架：Hono、Next.js/Nuxt.js、NestJS。
- 补充数据库（ORM）、数据验证（Zod）和进程管理（PM2）等关键工具。

**底层逻辑**
- 作者认为 JavaScript 生态足够强大，新手应优先利用社区已有方案而非重复造轮子。
- 学习路径应“模模糊糊”先动手实践，无需深究底层原理。
- 框架选择以项目规模和应用场景为驱动，而非盲目追求流行。

**Takeaways**
- 入门 Node.js 首选官方教程（nodejs.org/learn）和 MDN 的 Express 教程。
- 掌握常用框架：Hono（小型）、Next.js（中型）、NestJS（大型/求职）。
- 必学工具：ORM（简化 SQL）、Zod（数据验证）、PM2（进程守护）。
- 善用 GitHub 搜索现有方案，节省开发时间。
- 前端数据不可信，务必用 Zod 验证后再处理。
