# 和产品一起成长 - 从 AI 猫娘到 Prowl 终端
- URL: https://onevcat.com/2026/06/develop-with-ai/
- Added: 2026-06-08 02:07:39
- Tags: #agent #product

## TL;DR
作者分享了从单 agent 到多 agent 团队再到定制终端 Prowl 的演进，展示了工具随需求成长，工作习惯从专注转向碎片化持续调度，包含猫娘团队、身份映射、辩论机制及 Prowl 终端。

## Summary
- **核心主题**：作者分享了与 AI agent 协同工作流的演进，从个人使用猫娘 agent 到多 agent 团队协作，再到定制终端 Prowl，展示了工具随需求成长的过程，也反映了工作习惯从长时间专注转向碎片化、持续调度的变化。

- **关键信息与逻辑脉络**：
  - **移动端与 IM 环境下的 agent 协作**：
    - 初期使用 OpenClaw 在 Discord 上创建猫娘 agent，进行单 agent 任务，利用碎片时间开发项目（如 transcrab、xin）。
    - 由于单 agent 无法并行，扩展为三只猫娘团队，共享部分设定，各有专长，并引入“家庭关系”与人格漂移机制，通过邮件互评自调。
    - 身份问题：通过注入 agent id 实现 git/gh 映射，确保 agent 贡献可追溯。
    - 进一步集成 MeowHook webhook，使 agent 能直接在 GitHub、Linear 等平台上被调用（评论 @ 或 assign），形成任务池，实现自动化 CI 自愈等。
  - **多 agent 辩论机制**：
    - 利用多个模型喂养的猫娘，设计 argue 项目，让 agent 就同一问题辩论、收敛、投票生成报告，以兼听则明。
  - **桌面端终端 Prowl 的演化**：
    - 传统终端无法满足多 agent 并行工作需求，作者从 supacode fork 并大幅改造，形成原生 macOS 终端 Prowl，专为高效并行运行多个 AI coding agent 设计。
    - Prowl 已发展为个人日常工具，官方提供文档和互动介绍方式（提示语让 agent 解读）。
    - 官网可获取：prowl.cat 与 GitHub 仓库。
