## TL;DR
非技术人也能上手 Claude Code：从命令行、需求描述、项目规则到验收技巧，配合 Waza、Kami 等工具，让 AI 成为高效助手。

## Summary
本文面向非技术人员，系统介绍如何上手 Claude Code 这一 AI Coding 工具，从命令行入门到实战技巧，强调通过精确需求描述、项目规则文件和习惯沉淀实现高效协作。

**底层逻辑**：AI Coding 的核心不是让 AI 代写代码，而是通过清晰上下文（CLAUDE.md）、精确需求（写清背景、范围、异常、验收标准）、以及技能沉淀（Skill）来减少猜测，让人负责方向判断，AI 负责执行。

**Takeaways**：
- 克服命令行恐惧：使用 Kaku 终端降低门槛，安装 Claude Code 只需一条命令。
- 精准描述需求：写清楚“目标、范围、异常、验收标准”，避免模糊导致返工（如“首屏 1.5 秒内”比“页面要快”有效）。
- CLAUDE.md 是项目规则文件：用命令式语句，150 行以内，包含背景、规范、禁止项、压缩时保留项。
- 复杂任务先用 Plan 模式确认方向，再切 Auto 执行；验收三层：命令通过、眼见为实、逐条核对清单。
- 沉淀好习惯：通过 Waza 技能（/think 先方案、/check 收工检查）、Memory 跨项目记忆偏好，提升协作效率。
