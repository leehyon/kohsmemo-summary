# 先写 Skill 再执行
- URL: https://yage.ai/skill-first.html
- Added: 2026-06-03 05:30:12
- Tags: #agent #skill #advice

## TL;DR
用好 AI 的关键是先外化再执行，通过撰写 Skill 文档积累经验教训，实现知识复用，让 AI 越用越聪明。

## Summary
- 核心主题：用好 AI 的关键在于先外化 (externalize) 再执行，通过撰写 Skill 文档积累经验教训，实现知识复用，使 AI 越用越聪明。
- 关键信息：
  1. 常见误区：非技术人员认为本地 AI 工具（如 Claude Code）只能写代码；技术人员认为非代码任务仍用聊天框。两者都忽略了外化复用这一核心价值。
  2. 外化的本质：将完成任务的思路、方法、踩坑记录写成文档，让 AI 下次能直接参考，避免重复犯错。外化是复用的前提。
  3. Skill 的三大要素：
     - 成功标准：清晰描述最终目标，而非繁琐步骤（prompt for enablement）。
     - 踩过的坑：只记录 AI 真正犯过的错误，避免预判无关干扰。
     - 确定性工具：将可重复的底层操作（如搜索、发邮件）封装为工具，让 AI 直接调用。
  4. 组织方式：将所有 Skill 放入一个文件夹，用 index.md 做索引，通过 AGENTs.md 或 CLAUDE.md 自动加载，AI 像人一样按文档指示执行。
  5. 沉淀方法：在给 AI 的 prompt 末尾加上“根据写 Skill 的 Skill，先写一个 Skill 出来，然后照着做”，让 AI 自主更新文档。
- 逻辑脉络：
  - 提出问题：两种用户（非技术、技术）对本地 AI 工具存在误解，无法有效迁移工作方式。
  - 引出核心方法论：先外化再执行——AI 缺乏记忆，需将过程与知识文档化，才能复用。
  - 解释外化的实际意义：如同雇主给家政阿姨指令或程序员写代码，本质都是外化后执行。
  - 区分程序员与非程序员的思维盲区：程序员习惯代码复用，易忽视文档复用的价值；实际上文档比代码更通用。
  - 详细说明 Skill 的写法：三个要素（成功标准、坑、工具），以及如何利用已有 Skill 指导写作 Skill。
  - 提供组织案例：Skills 文件夹 + index.md + AGENTs.md 的层级结构，实现 AI 自动读取。
  - 强调习惯养成：每当重复性任务出现，先写 Skill 再执行，长期积累可大幅提升 AI 效率，释放人类脑力。
